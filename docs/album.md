# 回忆相册 · 金色回忆殿堂

独立路由：/album。页面：app/album/page.tsx。实时3D：app/components/MemoryScene.tsx。

## 视觉

按已确认的概念图制作：挑高的暗色金色大厅、拱形高窗、金色斜射光、浮尘、弯曲照片、镜面石材地面。独立相册页使用深棕金色界面，其余生活功能保留原来的浅色设计。

精细建筑使用专门生成的大厅背景图，位于public/art/memory-hall.png；空间内柱线、拱肋、照片、吊线、夹子、光束、浮尘与地面反射是实时3D。支持拖动环顾、滚轮/双指缩放进入、右键/双指平移及真实照片点击放大。场景不显示操作提示、按钮或进度滑杆。沉浸模式只留低显著度退出图标，Escape可退出。

纸张24×30细分平面，通过顶点着色器实现横向弯曲与随风波动，顶部悬挂点固定；朝向和高度错落，包含正面、背面、侧面。UnrealBloomPass实现暖光辉光，Reflector实时反射照片及建筑，半透明石材着色器形成地面纹理。限制像素比1.5与镜面分辨率768，最多60张实际照片；卸载释放纹理、几何体和后处理资源。

## 照片与后端

无用户照片时显示44张AI示意照片，来自public/art/memory-samples.png六格图集，页面下方明确说明示意性质。这些影像不插入用户数据库。上传真实照片后自动替换为用户影像。

上传JPG/PNG/WebP，单张8MB以内，一次最多12张，可填写标题、日期。支持放大、上一张/下一张与确认删除。

POST /api/photos上传，GET /api/photos/[id]读取，DELETE /api/photos/[id]删除。二进制存R2，元数据存D1，服务端按登录身份隔离并验证格式。

## 素材来源与生成提示

内置imagegen生成，非网络抓取。大厅提示：空置的挑高欧式暗色大厅、金色拱窗、暖光束、石材反射、无照片无人无文字；照片图集提示：3×2无边框旅行海岸、情侣日落、雨巷、花园、咖啡与海滩胶片照片。全部生成素材已复制到项目public/art，不引用外部生成临时路径。
