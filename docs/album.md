# 回忆相册

独立页面：/album。源文件：app/album/page.tsx。

参考悬浮照片墙：暗色空间、细线吊挂、具有景深的照片卡片、真实Three.js/WebGL三维空间、顶点着色器轻微弯曲和波动、围绕顶部悬挂点随风摆动。无照片时清晰展示上传入口，背景占位卡片不伪装真实回忆。最近60张照片以不同朝向和高度悬浮展示，全部记录可通过下方照片网格打开。

支持上传JPG、PNG、WebP，单张最大8MB，一次最多12张，可指定标题、日期。多文件留空标题时使用各自文件名。点击放大、前后切换、Escape关闭、沉浸模式、删除确认。

后端：POST /api/photos；GET /api/photos/[id]；DELETE /api/photos/[id]。图片二进制存储R2，元数据存储D1。服务端检查文件头、大小、身份和记录归属；图片请求不使用公共缓存。上传写数据库失败时尝试清理刚上传的对象。删除会先删除对象，再删除元数据；失败时显示重试。

本地数据库与R2状态由starter的.wrangler/state管理，与生产独立。

## 验收

上传照片后刷新，确认图片和标题、日期保留。进入沉浸模式，拖动环顾、滚轮或双指缩放前进、点击照片打开大图并切换；删除前确认。换账号不能访问前一账号图片。检查无照片状态、非法文件类型、超过8MB、批量部分失败及手机布局。

## 3D实现

独立组件app/components/MemoryScene.tsx。照片使用24×30细分平面，通过顶点着色器模拟纸张横向卷曲与风产生的波动，自上而下逐渐增加形变，顶部固定悬挂。OrbitControls支持拖动旋转、右键平移、滚轮和双指缩放；独立深度滑杆和前进/后退/重置按钮支持沿照片走廊浏览。射线检测区分拖动与点击，单击打开照片。组件卸载释放纹理、材质和几何体资源，像素比上限1.8。关闭减少动态效果时保留轻微静态卷曲，停止风动。WebGL不可用显示说明，下方网格依然可用。

## 空间呈现更新

去除场景内操作提示、进退按钮、深度滑杆及中心空状态遮罩。照片朝向覆盖正面、侧面和背面，高度错落分布；保留拖动、滚轮、双指操作和点击放大。场景右上方设置六格暖色窗户，五束半透明光锥穿过空间，并加入210个缓慢移动的细微尘粒。纸张以实际曲面法线估算窗光明暗，使不同朝向有自然的亮度差异。沉浸模式只保留低显著度退出图标。
