# 话题轮盘

独立路由：/wheel。页面源文件：app/wheel/page.tsx。类型数据：app/wheel/topics.ts。

所有26个子类型直接放在同一个轮盘，不需要选择主类型，不生成问题。

工作、吃喝、作息、小习惯、音乐、游戏、穿搭、旅行、童年、趣事、尴尬时刻、难忘回忆、恋爱经历、性经历、优点、缺点、害怕的事、反差、第一印象、共同回忆、好奇的地方、想一起做的事、理想型、心动瞬间、表达好感、相处边界。

点击中心或下方按钮开始旋转，停止后展示抽中的中英文子类型。旋转中禁止重复触发。指针准确指向被选中扇区中心；crypto随机数通过拒绝采样保证26项等概率。后台保留原主类型元数据，但页面没有主类型选择器。

抽取历史经 /api/records 写入D1，按账号隔离；支持读取、删除及失败重试。浏览器只执行抽取和动画，不作为持久化存储。

## 验收

确认26个扇区包含所有指定子类型，尤其是恋爱经历、性经历。点击旋转并检查指针与结果一致；多次旋转及旋转中重复点击；刷新后检查云端历史。窄屏检查扇区标签可读与交互可用。
