# 时光长河

入口：首页四个场景入口中的「时光长河」，独立路由 `/river`，不显示普通页面侧栏。默认铺满窗口，右上角可切换浏览器全屏。

W / ↑ 前进，S / ↓ 后退，A / ← 左移，D / → 右移；默认速度为原来的奔跑速度，不需要Shift；左下角按钮可按住移动，支持触屏。角色根节点和镜头位置固定，播放肢体行走动画；道路纹理、栏杆和路旁传送门沿固定弧形路径滚动。道路组件循环复用，不必走成闭合圆环。远景使用分层透明素材：云层独立缓慢流动，主城位置固定，小浮岛按不同相位上下和左右漂浮；这些远景都不跟随道路位移。角色屏幕位置固定，左右输入通过反向平移道路组表现，限制在道路宽度内。斜向移动速度经过归一化。

每18场景单位放置一扇门，交替位于道路左右的独立平台。日期以浏览器当地日期前三天为起点，使用日历加减天数，向前连续递增、向后连续递减，不因夏令时跳日期。门旁栏杆留有开口。进入门的实际平面距离7.3单位范围显示F提示，按F或点击提示打开当天聊天，Esc关闭。打开聊天、窗口失焦或页面隐藏时停止移动。

按用户要求预置四天的示例聊天，其他日期为空。示例日期和对话定义在 `app/river/timeline.ts`，页面和聊天窗口均标注「示例回忆」。没有自动读取或模拟用户真实ChatGPT聊天，没有写入数据库。将来连接实际聊天源时，应替换RiverChat数组，不能用日记或心情记录冒充聊天。

技术：Three.js WebGL、实时传送门着色器、Bloom、Blender原创骨骼角色、独立远景素材。角色源文件 `design/river-traveler.blend`，生成脚本 `tools/blender/build_traveler.py`，运行时资产 `public/models/river-traveler.glb`；通过GLTFLoader和AnimationMixer播放Idle/Run动画，原地切换，不驱动角色位置。模型读取失败时明确提示并显示简化替身。WebGL不可用时显示明确提示。

道路和门框也在Blender建模，见 `tools/blender/build_environment.py` 与 `design/river-architecture.blend`。运行时加载 `public/models/river-architecture.glb`；道路、左右栏杆、地面纹章使用InstancedMesh复用。路面有烘焙大理石纹理、倒角石板、间隔罗盘镶嵌，栏杆采用回转雕刻石柱，门框包含槽柱、金叶、拱边和阶梯基座。启用天空环境反射与实时软阴影，发光门含实时星尘和局部光源。模型加载完成前展示进入场景状态，避免简化替身闪现。
