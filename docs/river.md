# 时光长河

入口：首页四个场景入口中的「时光长河」，独立路由 `/river`，不显示普通页面侧栏。默认铺满窗口，右上角可切换浏览器全屏。

W / ↑ 前进，S / ↓ 后退，Shift 加速；左下角按钮可按住移动，支持触屏。角色根节点和镜头位置固定，播放肢体行走动画；道路纹理、栏杆和路旁传送门沿固定弧形路径滚动。道路组件循环复用，不必走成闭合圆环。远处的云海、浮岛和宫殿使用固定背景画，不跟随移动。

每18场景单位放置一扇门，交替位于道路左右的独立平台。日期以浏览器当地日期前三天为起点，使用日历加减天数，向前连续递增、向后连续递减，不因夏令时跳日期。门旁栏杆留有开口。进入纵向5.2单位范围显示F提示，按F或点击提示打开当天聊天，Esc关闭。打开聊天、窗口失焦或页面隐藏时停止移动。

按用户要求预置四天的示例聊天，其他日期为空。示例日期和对话定义在 `app/river/timeline.ts`，页面和聊天窗口均标注「示例回忆」。没有自动读取或模拟用户真实ChatGPT聊天，没有写入数据库。将来连接实际聊天源时，应替换RiverChat数组，不能用日记或心情记录冒充聊天。

技术：Three.js WebGL、实时传送门着色器、Bloom、原创程序化低多边形角色、固定生成式远景背景 `public/art/river-sky.jpg`。当前角色是简化模型，场景并非概念图中的精细角色资产。WebGL不可用时显示明确提示。
